# 10-Point Standard Curve Example Plate Layout

96 well plate map in a wide format used in the lab, used for when
10-point standard curves are required for pk/pf/pv analysis. Contains
information of actual Sample ID names in each well.

## Format

A data frame with 9 rows and 13 variables.

- Plate:

  Contains rows labelled "A" to "H"

- 1-12:

  Contains columns labelled "1" to "12"

## Details

This file is stored in inst/extdata
